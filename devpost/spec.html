Architecture & Data Flow

Technology Stack

Calibrated for zero-latency in-browser execution, total data privacy, and zero server complexity:

  • ⚡ Vite 6 + React 19: Fast local development server, instant hot reload.
  • 🎨 Tailwind CSS v3: Executive dark SaaS aesthetic with custom risk palettes.
  • 📄 pdfjs-dist (v4): 100% in-browser PDF text extraction engine.
  • 🛡️ Lucide React: Crisp modern icons for badges, cards, and copy triggers.

Modular Rules Registry (Teaching New Legalese)

Solves the user's question regarding modern legal workarounds by decoupling rule definitions from UI code:

// src/services/rulesRegistry.js
export const RULES = [
  {
    id: 'unpaid-maintenance',
    category: 'Scope & Revisions',
    severity: 'critical', // -25 pts
    patterns: [ /(?:rectify|remedy|correct).*(?:perpetual|indefinite|free)/i ],
    explanation: 'Exposes you to unlimited uncompensated work post-launch.',
    counterProposal: 'Hi [Client], standard practice is a 30-day warranty...'
  }
];
