🗺️ FairShare — App Architecture Map

Take-home developer reference guide created for the Devpost Learn Hackathon

App Purpose & Anatomy

FairShare is a client-side legal tech tool that protects freelancers from predatory contract clauses. It parses agreements directly in the browser, calculates a real-time Contract Health Score across 4 risk categories, highlights dangerous sentences, and provides 1-click polite counter-proposals ready to email to clients.

The Code Route: Follow a Contract Through the System

1
The Entry Point — src/components/ContractInput.jsx

Captures user actions: dropping a PDF, pasting contract text, or loading the sample. For PDF uploads, it invokes extractTextFromPdf() in pdfParser.js, loading Mozilla's pdfjs-dist in-memory without sending anything to an external server.

2
The Intelligence Core — src/services/contractSentinel.js

Executes the analyzeContract() function. It iterates over the rule catalog defined in rulesRegistry.js, applies semantic regex clusters to detect traps (unpaid maintenance, Net-90, IP grabs, non-competes), computes deductions for the 0–100 Health Score, and records character offsets for interactive highlighting.

3
The Executive Split Workspace — src/components/WorkspaceView.jsx

Coordinates the split screen. It passes character offsets to DocumentViewer.jsx to render clickable <mark> spans, mounts the animated SVG HealthScoreGauge.jsx, renders individual RiskCard.jsx items, and triggers the diplomatic NegotiationModal.jsx.

To Change This, Start Here

  • 🔹 To add a new legal clause or trap: Open src/services/rulesRegistry.js and add a new rule object to the RULES array with its regex patterns, penalty, explanation, and counter-proposal.
  • 🔹 To adjust the scoring severity: Tweak the penalty values in src/services/rulesRegistry.js.
  • 🔹 To refine the email pushback wording: Update the counterProposal string templates in src/services/rulesRegistry.js or the modal envelope in src/components/NegotiationModal.jsx.

A Practice to Reuse in Future Projects

The Rule Registry Pattern

When building apps with domain-specific logic (like legal auditing, code linting, medical jargon checking, or finance rules), never hardcode detection rules or text snippets inside React UI components.

By centralizing all legal logic in rulesRegistry.js, our application is modular, instantly extensible, and can be unit-tested without rendering a single browser component. This pattern allows non-developers or legal experts to update rules by editing a simple data file!
